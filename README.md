# Silent Noisy Hooks Python Demo

This example demonstrates the 'silent hook' and 'noisy hook' metaphors for coding assistants. The 'silent hook' provides warnings about potential style issues without blocking execution, similar to a linter. The 'noisy hook' enforces critical rules and halts execution upon violation, mimicking a pre-commit check or strict build process.

## Language

`python`

## How to Run

Save the code as `main.py`. Run from your terminal: `python main.py`.
